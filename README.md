# Web Minecraft（React + Three.js，参考 1.8.9）

一个运行在浏览器里的体素生存世界：Vite + React 19 + TypeScript + three.js，贴图与生物模型全部程序化生成，无外部资源。

## 功能

- **四种模式**：生存 / 创造（无限物品、飞行、秒破）/ 冒险（不能破坏与放置方块）/ 极限（困难难度，死亡即删档）
- **世界**：水平方向无限、高度 256（按 16×16×16 分段惰性存储，空段不占内存），海平面 63，simplex 噪声地形，12 种群系（海洋 / 平原 / 森林 / 桦木林 / 黑森林 / 针叶林 / 雪原 / 沙漠 / 热带草原 / 丛林 / 沼泽 / 山地），洞穴、矿脉、树木、花草、湖海；每个 chunk 只由种子与坐标决定，可随时丢弃再生
- **世界类型**：默认噪声地形 / 超平坦（基岩 + 泥土 + 草，1.8 经典预设）
- **结构**：村庄（水井、房屋、小路，平原与沙漠两种风格，随地形找平），主菜单可关闭
- **火**：打火石点火，火按固定节奏蔓延到紧挨可燃方块（木板 / 原木 / 树叶 / 羊毛 / 书架）的空气里，
  烧久了会吃掉脚下的方块，没燃料就熄灭；站进火里或岩浆里会被点燃
- **桶**：空桶装水 / 岩浆源、装满的桶倒出流体源，对着牛右键挤奶（牛奶暂时只是喝完变空桶）
- **岩浆**：与水共用一套流体模拟（只流 3 格、更新更慢、没有无限源），发光 15、泡进去掉血并点燃；
  岩浆碰到水会凝固——源变黑曜石、流动的变圆石
- **水**：1.8 规则的流动水——源 / 流动 / 下落水位、落差寻路、无限水、断源消退，水面斜面渲染，水流推动实体，游泳时贴岸可自动攀出
- **方块**：约 50 种；木板 / 原木 / 树叶 / 树苗各 6 种木材、羊毛 16 色、石头 3 变种 + 磨制版，
  与 1.8.9 一样用 meta 区分变体，
  含半砖与楼梯等非整方块——按点击位置分上下半、按朝向摆放，两块同种半砖可合并成整块；
  箱子有 27 格存储、床可睡觉、梯子可攀爬、木门与栅栏门可开合、栅栏按四邻自动连成一片
- **状态效果**：迅捷 / 缓慢 / 力量 / 虚弱 / 生命恢复 / 中毒 / 凋零 / 跳跃提升 / 抗火 /
  水下呼吸 / 夜视 / 隐身 / 瞬间治疗 / 瞬间伤害，HUD 右上角显示剩余时间，喝牛奶清空
- **成就与统计**：1.8.9 成就树的 25 项（含前置关系），解锁时弹提示；暂停菜单里可查看成就页与统计
  （游戏时长 / 挖掘放置 / 合成 / 击杀 / 死亡 / 伤害 / 跳跃 / 附魔 / 酿造），随存档保存
- **附魔与铁砧**：附魔台（书架加成、三档等级消耗、按 1.8.9 权重抽附魔）出 12 种附魔——效率 / 精准采集 /
  时运 / 锋利 / 击退 / 火焰附加 / 抢夺 / 保护 / 火焰保护 / 摔落保护 / 水下呼吸 / 耐久，书可附成附魔书；
  铁砧可用材料或同物品修复、合并附魔、套附魔书、改名（消耗等级）
- **酿造与药水**：烈焰棒 + 圆石合成酿造台，玻璃瓶对水装水瓶，水瓶 + 下界疣 → 粗制药水，
  再按 1.8.9 的原料表酿出 13 种效果药水，红石延长 / 萤石增强 / 火药变喷溅、发酵蛛眼反转效果；
  普通药水右键喝、喷溅药水扔出去砸到生物或方块后对 4 格内的活体生效（越远越短）。
  下界疣 / 恶魂之泪 / 烈焰棒等下界材料在下界做出来之前只能从创造模式取
- **天气**：晴 → 雨 →（有几率）雷雨循环，下雨时天光压暗、雾变灰、露天的火被浇灭，
  冷群系下雪；天气随存档保存
- **光照**：天空光 + 方块光（火把、萤石）BFS 传播，平滑光照 + AO，昼夜循环（20 分钟一天）与星空
- **生存**：血量、饥饿、经验、护甲（4 个装备槽，每点护甲减伤 4%、受伤磨损耐久）、挖掘进度与工具等级、掉落物与经验球拾取、摔落 / 溺水伤害、死亡与重生；
  床可设重生点，夜里附近没怪时一觉睡到天亮
- **农业**：锄地成耕地（附近有水保持湿润）、种小麦 / 胡萝卜 / 土豆、随机 tick 按湿度分阶段生长、成熟收获；
  树苗会长成树、草会向露天的泥土蔓延
- **合成**：背包 2×2、工作台 3×3（有序/无序配方，含镜像），熔炉烧炼
- **生物**：友善——猪、牛、羊、鸡、鱿鱼（掉墨囊）、蝙蝠（拿对应的食物右键可喂食繁殖，幼崽 20 分钟长大；剪刀可剪羊毛，羊 2 分钟后长回）；敌对——僵尸、骷髅（射箭）、苦力怕（爆炸）、蜘蛛（夜间敌对）、末影人（受伤瞬移）、史莱姆（死亡分裂）；夜晚 / 黑暗处刷怪，白天阳光下僵尸骷髅燃烧
- **存档**：IndexedDB 本地存档（只保存被修改过的 chunk，RLE 压缩；旧版整卷存档自动迁移），主菜单新建 / 读取 / 删除，游戏内保存与 5 分钟自动保存

## 操作

| 按键 | 作用 |
|---|---|
| WASD / 空格 / Shift / Ctrl | 移动 / 跳跃 / 潜行 / 疾跑 |
| 鼠标左键 | 挖掘 / 攻击 |
| 鼠标右键 | 放置方块 / 使用（进食、打开工作台或熔炉、点燃 TNT） |
| 滚轮 / 数字键 1-9 | 切换快捷栏 |
| E | 背包（含 2×2 合成） |
| Q（Ctrl+Q） | 丢弃 1 个（整组） |
| F3 | 调试信息 |
| Esc | 暂停菜单（渲染距离、保存、退出） |
| 双击空格 | 创造模式飞行 |
| 鼠标中键 | 创造模式选取方块 |

按键与鼠标灵敏度可在**设置**里修改（主菜单标题下方或暂停菜单 → 设置），支持按键交换与一键恢复默认，配置存在浏览器本地。

## 手机（横屏）

竖屏时会提示旋转设备，横屏后进入游戏。触屏设备自动显示基岩版风格的操作层：

| 操作 | 作用 |
|---|---|
| 左下摇杆 | 移动 |
| 拖动屏幕 | 转视角 |
| 轻点屏幕 | 放置 / 使用（等同右键） |
| 右下「挖掘」按住 | 挖掘 / 攻击 |
| 右下「跳跃」「潜行」 | 跳跃（创造模式连点两次飞行）/ 潜行下降 |
| 顶部「背包」「丢弃」「暂停」 | 对应 E / Q / Esc |
| 点快捷栏格子 | 切换手持物品 |
| 背包内长按格子 | 等同右键（取一半 / 放一个） |

不想要按钮可以在设置里关掉「显示触屏按钮」，触屏视角灵敏度也可单独调整。

## 开发

```bash
npm install
npm run dev        # http://localhost:5173
npm run typecheck  # tsc
npm run lint       # oxlint
npm run test       # vitest 单元测试
npm run build      # 生产构建 → dist/
npm run preview
```

端到端冒烟（需 `npx playwright install chromium`，先启动 dev server）：

```bash
E2E_URL=http://localhost:5173/ npm run e2e
```

## 目录

```
src/
├── engine/           # 与 React 无关的游戏引擎
│   ├── Game.ts       # 主循环、输入、玩法逻辑编排（实现 EntityContext / ContainerHost）
│   ├── constants/    # 常量：世界/分块、流体、玩家属性、生物、键位、存档
│   ├── blocks/       # 方块注册表与挖掘计算
│   ├── items/        # 物品注册表、背包、配方、熔炉、容器点击逻辑
│   ├── textures/     # 程序化像素贴图、图集、UI 图标
│   ├── world/        # 分块 World、ChunkManager 流式加载、地形/超平坦生成器、村庄结构、光照、流体、chunk 网格
│   ├── physics/      # AABB 碰撞、射线
│   ├── entities/     # 实体基类、生物 AI、掉落物、箭矢、刷怪
│   ├── player/       # 玩家状态、键鼠控制
│   ├── render/       # three.js 渲染：chunk 着色器、天空、实体模型、手持物、音效
│   ├── modes/        # 四种游戏模式规则
│   ├── save/         # RLE 序列化 + IndexedDB 存档 + 旧格式迁移
│   └── events/       # UI 状态 Store
├── ui/               # React 组件：主菜单、HUD、背包 / 工作台 / 熔炉、暂停、死亡、调试
└── styles/
tests/                # vitest：地形、村庄、光照、流体、碰撞、物品/配方/熔炉、容器交互、存档迁移
e2e/                  # playwright 冒烟脚本
```
